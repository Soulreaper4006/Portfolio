Portfolio personnel bilingue (FR / EN), entièrement statique et gratuit à héberger. Construit avec React + Vite.

## Démo

🔗 **[Voir le portfolio en ligne](https://portfolio-dassonville-ugo.vercel.app)** — hébergé sur Vercel

## Fonctionnalités

- **Design Moderne** — thème sombre avec accents indigo/cyan, dégradés et typographies Space Grotesk / Inter / JetBrains Mono
- **Animations Dynamiques** — terminal animé, effets de typing, apparitions au scroll et transitions hover
- **Bilingue FR / EN** — switcher de langue persistant (localStorage), tout le contenu est traduit
- **Responsive** — adapté à tous les types d'écrans, avec menu burger sur mobile
- **Sections Complètes** — Accueil, Projets (6 projets reliés à leurs dépôts GitHub), CV, Contact
- **CV** — versions HTML (`/cv-fr.html`, `/cv-en.html`), export en PDF via Imprimer → Enregistrer en PDF
- **Performances Optimales** — construit avec Vite pour un build statique rapide

## Technologies Utilisées

**Frontend**

- **React 19.2.8** — Bibliothèque JavaScript pour l'interface utilisateur
- **React DOM 19.2.8** — Rendu du DOM pour React
- **Vite 8.3.0** — Build tool et dev server ultra-rapide

**Développement**

- **oxlint** — Linting du code (rapide et zéro config)
- **CSS personnalisé** — Design system maison, stylé avec des dégradés et des effets futuristes
